# Portfólio Web — versão sem editor no navegador

O editor visual foi removido. O visitante apenas visualiza o portfólio.

Para alterar conteúdo, competências, projectos, experiências, imagens ou estilos, é necessário editar os ficheiros na máquina:

- `index.html` — estrutura da página;
- `style.css` — aparência e responsividade;
- `script.js` — dados e funcionalidades.

A foto de perfil também foi removida.

Os identificadores criados para o projecto usam português, incluindo nomes de classes, IDs, funções e variáveis.

## Executar

Abra `index.html` no navegador ou use o Live Server no VS Code.

## Importante
Isto impede a edição através de uma interface no site, mas HTML, CSS e JavaScript enviados ao navegador continuam tecnicamente acessíveis através das ferramentas de programador. Se o objectivo for esconder o código-fonte, será necessário usar backend, autenticação e uma arquitectura adequada.
